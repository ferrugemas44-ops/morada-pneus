## 📌 Sobre o projeto

A proposta foi criar um site com uma identidade visual forte e uma estrutura simples para apresentar a empresa, seus produtos e serviços.

O layout foi pensado para facilitar a navegação e permitir que o visitante encontre rapidamente as informações importantes.

### Seções do projeto

* 🏠 Início
* 🛞 Pneus
* 🔧 Serviços
* ℹ️ Sobre
* 📞 Contato

---

## 🎨 Identidade visual

O projeto utiliza uma combinação de:

* ⚫ Preto
* 🔴 Vermelho
* 🟡 Amarelo
* ⚪ Branco

As cores foram escolhidas para criar uma identidade visual relacionada ao segmento automotivo e transmitir uma aparência forte e marcante.

---

## 📱 Responsividade

O site foi desenvolvido pensando em diferentes tamanhos de tela, buscando manter uma boa experiência tanto no computador quanto em dispositivos móveis.
